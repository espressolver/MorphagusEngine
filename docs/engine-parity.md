# Engine parity with the reference engine

The web engine reimplements the HP (KnowWonder UE1) engine. The HP2 engine source (a later build of the
same engine, `HarryPotter2/Unreal`) is used as the behavioural reference: each module is compared function by
function, reimplemented in our own JS, and covered by parity tests (`tests/parity-*.test.mjs`).
Where HP1's own scripts or data clearly differ from HP2 (HP1 shipped on the earlier build), HP1 wins.

Status: ✅ compared + ported + tested · 🟡 compared, partly ported · ⬜ not compared yet
